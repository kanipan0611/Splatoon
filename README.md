# 🦑 Splatool — スプラトゥーン3 上達支援ツール

プレイ動画のAI分析・AIコーチ相談・戦績管理・立ち回り知識ベースがひとつになった、スプラトゥーン3の上達支援Webアプリです。**無料で使えます**(下記「無料で使う3つの方法」参照)。

## 機能

| 機能 | 内容 |
|---|---|
| 🎬 **動画分析** | プレイ動画(MP4等)をアップロードすると、フレームを自動抽出し「画面変化が大きい瞬間(キル/デス/スペシャル候補)」を検出。AI接続時はコーチが**良かった点・改善点・練習メニュー**をレポート。オフライン時は**セルフレビューガイド**を表示 |
| 🤖 **AIコーチ相談** | 「エリアの打開がうまくいかない」など、立ち回りの悩みをチャットで相談 |
| 📊 **試合記録・統計** | ルール/ステージ/ブキ/K/D等を記録し、勝率やK/D推移をグラフ化。5戦以上でAIによる戦績傾向分析も |
| 📚 **知識ベース** | ルール別・ブキ種別の立ち回りTips、ギアの基本、セルフレビューチェックリスト(完全オフライン) |

## 無料で使う3つの方法

サイドバーの「AIバックエンド」で選択できます。

### 1. Gemini API の無料枠(おすすめ)
[Google AI Studio](https://aistudio.google.com/apikey) でGoogleアカウントがあれば**無料・クレジットカード不要**でAPIキーを発行できます。画像分析(動画のAI分析)にも対応。無料枠にはレート制限があるため、連続で分析するときは少し間隔を空けてください。

### 2. Ollama(ローカルAI・完全無料)
そこそこの性能のPC(メモリ8GB以上目安)があれば、AIを自分のPCで動かせます。通信量・利用料ゼロ。

```bash
# https://ollama.com からインストール後
ollama pull llava        # 画像対応・軽量モデル
# 余裕があれば: ollama pull qwen2.5vl   (高精度)
```

アプリのサイドバーで「Ollama」を選ぶだけで接続します。精度はクラウドAIに劣りますが完全無料です。

### 3. オフラインモード(AIなし・完全無料)
AIを一切使わなくても以下が使えます:

- 動画の**注目シーン自動検出 + セルフレビューガイド**(チェックリストに沿って自分で振り返る)
- 試合記録・統計グラフ
- ルール別・ブキ種別の立ち回り知識ベース

> 💡 より高精度な分析が欲しい場合は Claude API(有料・従量課金)も選べます。

## セットアップ

Python 3.10 以上が必要です。

```bash
git clone https://github.com/kanipan0611/Splatoon.git
cd Splatoon
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。APIキーはサイドバーから入力できます(環境変数 `GEMINI_API_KEY` / `ANTHROPIC_API_KEY` でも可)。

## 動画分析の使い方のコツ

- **Switch本体のキャプチャ(30秒クリップ)がおすすめ。** SDカードの `Nintendo/Album` からMP4を取り出せます。デスした直後にキャプチャボタン長押しで、直前30秒を保存できます。
- キャプチャボード録画の長い動画も対応していますが、フレームを間引いてAIに送るため、**「見てほしい場面を含む短いクリップ」ほど分析精度が上がります**。
- 「特に見てほしいポイント」欄に悩み(例: すぐデスする、打開が苦手)を書くと、その観点を重点的に分析します。

## 構成

```
Splatoon/
├── app.py                    # Streamlitアプリ本体
├── splatool/
│   ├── video_analyzer.py     # フレーム抽出・注目シーン検出 (OpenCV)
│   ├── providers.py          # AIバックエンド抽象化 (Claude / Gemini / Ollama)
│   ├── ai_coach.py           # コーチングプロンプトと分析ロジック
│   ├── match_log.py          # 試合記録 (SQLite)
│   └── knowledge.py          # 立ち回り知識ベース・セルフレビューチェックリスト
├── data/matches.db           # 試合記録DB (自動生成・git管理外)
└── requirements.txt
```

## 注意事項

- Gemini無料枠のレート制限や提供条件はGoogle側の規約により変わることがあります。
- 本ツールは非公式のファンメイドツールです。任天堂およびスプラトゥーン3とは関係ありません。
