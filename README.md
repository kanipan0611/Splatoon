# 🦑 Splatool — スプラトゥーン3 上達支援ツール

プレイ動画のAI分析・AIコーチ相談・戦績管理・立ち回り知識ベースがひとつになった、スプラトゥーン3の上達支援Webアプリです。

## 機能

| 機能 | 内容 | APIキー |
|---|---|---|
| 🎬 **動画分析** | プレイ動画(MP4等)をアップロードすると、フレームを自動抽出し「画面変化が大きい瞬間(キル/デス/スペシャル候補)」を検出。AIコーチが**良かった点・改善点・練習メニュー**をレポート | 必要 |
| 🤖 **AIコーチ相談** | 「エリアの打開がうまくいかない」など、立ち回りの悩みをチャットで相談 | 必要※ |
| 📊 **試合記録・統計** | ルール/ステージ/ブキ/K/D等を記録し、勝率やK/D推移をグラフ化。5戦以上でAIによる戦績傾向分析も | 不要(AI分析のみ必要) |
| 📚 **知識ベース** | ルール別・ブキ種別の立ち回りTips、ギアの基本などをオフラインで閲覧 | 不要 |

※APIキー未設定でもオフライン版(定型アドバイス)で動作します。

## セットアップ

Python 3.10 以上が必要です。

```bash
git clone https://github.com/kanipan0611/Splatoon.git
cd Splatoon
pip install -r requirements.txt
```

### AI機能を使う場合(推奨)

[Anthropic Console](https://console.anthropic.com/) でAPIキーを取得し、環境変数に設定します。

```bash
export ANTHROPIC_API_KEY="sk-ant-..."   # Windows: set ANTHROPIC_API_KEY=sk-ant-...
```

アプリ起動後にサイドバーから入力することもできます。

## 起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## 動画分析の使い方のコツ

- **Switch本体のキャプチャ(30秒クリップ)がおすすめ。** SDカードの `Nintendo/Album` からMP4を取り出せます。デスした直後にキャプチャボタン長押しで、直前30秒を保存できます。
- キャプチャボード録画の長い動画も対応していますが、フレームを最大20枚に間引いてAIに送るため、**「見てほしい場面を含む短いクリップ」ほど分析精度が上がります**。
- 「特に見てほしいポイント」欄に悩み(例: すぐデスする、打開が苦手)を書くと、その観点を重点的に分析します。

## 構成

```
Splatoon/
├── app.py                    # Streamlitアプリ本体
├── splatool/
│   ├── video_analyzer.py     # フレーム抽出・注目シーン検出 (OpenCV)
│   ├── ai_coach.py           # Claude APIによる分析・コーチング
│   ├── match_log.py          # 試合記録 (SQLite)
│   └── knowledge.py          # 立ち回り知識ベース
├── data/matches.db           # 試合記録DB (自動生成・git管理外)
└── requirements.txt
```

## 注意事項

- AI分析にはAnthropic APIの利用料金がかかります(動画1本あたり画像約20枚+レポート生成)。
- 本ツールは非公式のファンメイドツールです。任天堂およびスプラトゥーン3とは関係ありません。
